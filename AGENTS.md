# Working on FixTrack

Read [FixTrack Master Context](documentation/MASTER_CONTEXT.md) at the start of a FixTrack task. It explains the product, current implementation, access rules, and planned milestones.

Use the [README](README.md) for local setup, [development notes](documentation/DEVELOPMENT.md) for architecture and API details, and [contribution guide](CONTRIBUTING.md) for team workflow. Verify current behavior in the checked-out code and tests. Update the master context when a change affects the documented product behavior, architecture, or scope.
